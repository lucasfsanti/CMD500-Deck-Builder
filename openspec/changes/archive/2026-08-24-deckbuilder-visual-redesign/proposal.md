## Why

The deckbuilder's full-tab view (`extension/src/tab/TabRoot.tsx`, `extension/src/ui/panel.css`) hasn't been visually revisited since it was built. Three concrete problems make it a poor use of a full browser tab: `BudgetGauge` and `CardCountGauge` are near-duplicate half-circle gauges stacked in a cramped 300px sidebar; the "Cor" (color) analytics chart throws away real color-identity data by rendering every bucket — mana curve, color, and type alike — in one flat forest-green bar; and the Commander, which defines a Commander deck's whole identity, gets the same narrow-column visual weight as a Maybeboard. Separately, `panel.css` still carries a full set of rules (`.c500-panel`, `.c500-gauge` container variants, `.c500-legality`, `.c500-export`) for a floating overlay panel that a prior change (`deck-tab-view`) already removed from the product — `content-script.ts` mounts no UI at all now. This redesign re-skins the one surface that remains (the full-tab view) with a more deliberate palette, typography, and layout, and removes the dead overlay CSS along the way.

## What Changes

- Replace the token system in `panel.css` (`--c500-*` custom properties) with a dark, cool-neutral "Night Ledger" palette — a near-black canvas with muted, desaturated accents — in place of the original warm parchment direction, which (like the parchment-plus-serif look it replaced) still read as a generic AI-design default rather than a considered choice. The mana-identity structure is unchanged: green/red/gold still double as good/bad status and the multicolor/price accent, just rendered in restrained, lower-saturation hues against near-black instead of saturated hues against cream. White, blue, and black remain the three net-new hues; the low-contrast "needs a keyline" problem moves from white (illegible against light parchment) to black (illegible against near-black) — same principle, mirrored.
- Drop the serif display typeface entirely in favor of one grotesk for every role (zone headers, chart titles, the page title, body text); only the monospace stack stays distinct, for tabular numerals. Character now comes from weight, scale, and spacing on a single sans family, not a serif/sans pairing.
- Remove the ledger tape's vertical divider lines between items (budget, count, legality, controls, export), relying on spacing alone to separate them — a quieter reading than the original "segmented receipt" treatment.
- Consolidate `BudgetGauge` + `CardCountGauge` + `LegalitySummary` + `ExportMenu` into a single full-width horizontal strip below the header (the "ledger tape"), replacing the current stacked-in-a-sidebar arrangement of two duplicate circular gauges.
- Add a color-identity rail to `CardRow` and `CardVisualTile`: a thin colored left edge derived from `card.enrichment.colorIdentity` (already present on every enriched `DeckCard`, no new data needed) — solid mana hue for mono-color, gold for multicolor, stone gray for colorless, neutral while enrichment is pending.
- Recolor the "Cor" `BarChart` bucket-by-bucket using the same seven color tokens (1:1 with `colorBuckets()`'s existing `White/Blue/Black/Red/Green/Multicolor/Colorless` labels); leave the Curva (mana curve) and Tipo (type) charts on a single neutral hue, since CMC and card type carry no color-identity meaning.
- Restructure `TabRoot.tsx`'s layout: header → full-width ledger tape → a main content row placing Deck Principal (dominant width) beside a left column holding the Commander hero block (Comandante and Comandante Parceiro side by side) with Maybeboard beneath it → a full-width analytics band (Curva/Cor/Tipo) below the main content row. This puts Deck Principal at the same vertical position as the Commander hero, visible without scrolling, instead of below a full-width hero+analytics band. View toggle and grouping controls move into a slim control row instead of dedicated sidebar blocks.
- Remove the dead `.c500-panel` overlay-panel CSS (the container, and the `.c500-gauge`/`.c500-legality`/`.c500-export` rules that only that removed overlay used) from `panel.css`; fold the two still-used sub-classes (`c500-panel__mark`, `c500-panel__format`) into the redesigned header under the new naming/token system.
- Replace the Lista/Visual toggle's text-labeled buttons with icon-only buttons, preserving each control's accessible name via `aria-label` now that the icon carries no visible text.
- Increase the default (non-hero) card artwork size used by Visual-mode grid tiles and the List-mode hover preview, for better readability.
- Remove the visible name caption from non-hero Visual-mode grid tiles (Deck Principal, Maybeboard); the Commander hero tile keeps its caption. The name stays available as the artwork's alt text; the "missing artwork degrades to a placeholder" behavior is untouched — a card with no resolvable art still shows its name as the placeholder's own content.
- Bump the base type scale slightly across the design system, and introduce a dedicated `--c500-price` token (darker than the shared `--c500-mana-gold`) for price text specifically, so price contrast improves without shifting the multicolor rail or ledger accents that also use gold.
- Rename the "Deck Principal" zone label to "Main Deck", and "Comandante Parceiro" to "Companheiro".
- Move the analytics band (Curva/Cor/Tipo) from a full-width row below the main content into a third column to the right of Deck Principal, stacking the three charts vertically within that column; reduce `.c500-tab__body`'s side padding and widen its max-width to comfortably fit three columns.
- Move Companheiro back to stacking below Comandante (reverting the prior round's side-by-side sizing) and give it a shrink-when-empty state: a small collapsed slot when it holds no card, expanding to full hero height once a card lands there.
- Give Deck Principal's List view a Moxfield-style multi-column grouped layout (each type/color/cmc group flows into its own column via CSS multi-column, rather than stacking as one long vertical list); scoped to Deck Principal only — Maybeboard's narrower column keeps a single stacked list.
- A second pass of enlarging non-hero card sizing (both List row height/font and Visual tile size) for readability, beyond the previous round's bump.
- The Comandante zone's card no longer exposes a removal control (TabRoot simply omits `onRemoveCard` for that zone's `ZoneSection`) — a disclosed exception to deck-organizer's "any card" removal requirement, since the format's defining card is corrected by replacing it via drag, not deleted. Its quantity field was already structurally impossible to show (the non-basic-land gate), so no change needed there.
- Enlarge the basic-land quantity input and fix its digit visibility (currently too small for the number inside to render clearly).
- Make the ledger tape (budget, card count, legality, view/grouping controls, export) stick to the top of the viewport as the page scrolls, and make the analytics column (Curva/Cor/Tipo) stick beneath it — both stay visible while Deck Principal, the tallest column, scrolls past them. The hero column (Comandante/Companheiro/Maybeboard) is not included.
- Add a global "Ordenar por" (sort by) select next to the existing grouping select — Custo de Mana (default, ascending), Nome (alphabetical), Cor (colorless/W/U/B/R/G/multicolor order), or Valor (R$, descending, highest first) — that now explicitly determines each zone's within-group card order, applying to all zones at once. This replaces the previous automatic, non-configurable "sort by the two axes not used for grouping, then name" rule with direct user control; name stays the tiebreak. Cards with an unresolved price sort after all priced cards when the sort axis is Valor.
- `BudgetGauge` shows both the amount used and the amount remaining (e.g., "R$414,27 usados · R$85,73 restantes"), replacing the current "spent / of R$500 limite" pairing.
- Group labels (the type/color/cmc sub-headers within a zone, e.g. "CRIATURA") gain a card count matching the zone header's own `(N)` count style, plus a larger, higher-contrast treatment.
- The mana curve chart excludes land cards entirely — a 0-cost land bucketed alongside genuinely free spells was cluttering the curve with data that isn't really about mana cost.
- The color-distribution chart gains a dedicated "Terrenos" bucket counting all land cards' full quantity, pulled out of the normal color-identity buckets — a dual land no longer gets split into a color bucket its color identity doesn't meaningfully represent.

This is a presentation-layer redesign: no deck logic, data model, capture behavior, export formats, legality rules, or budget/card-count calculation changes. **Not breaking** in the product sense (same features, same data), though every CSS class name and the DOM structure of `TabRoot.tsx` and its child components will change.

## Capabilities

### New Capabilities
_None._ This change introduces no new user-facing behavior or system capability — see design.md for the full visual-system rationale.

### Modified Capabilities
- `card-visual-view`: the Commander hero block (Comandante/Comandante Parceiro) always renders in Visual mode — real artwork, or the same placeholder Visual view already uses when art can't be resolved — regardless of the List/Visual toggle. Every other zone (Deck Principal, Maybeboard) still follows the toggle exactly as before. This is a disclosed, deliberate exception to the existing "single control... applying to all zones at once" requirement, surfaced while walking the spec's scenarios against the implementation (see design.md's Decisions), not an incidental side effect.
- `card-visual-view`: the "Visual view shows artwork with identifying and pricing information" requirement is narrowed — the name caption is now Commander-hero-only; Deck Principal and Maybeboard grid tiles show artwork and price but no visible name caption (the name stays available as the artwork's alt text). Artwork, price, and the basic-land quantity field remain unchanged everywhere.
- `deck-organizer`: the "Explicit card removal" requirement is narrowed to exclude the primary Comandante, which no longer exposes a removal control — the format's defining card is corrected by dragging a replacement into Comandante, not by deleting it. Every other zone's removal behavior is unchanged.
- `deck-organizer`: the "Grouping and sorting within a zone" requirement's within-group sort is replaced — instead of an automatic, fixed "sort by the two non-grouping axes, then name" rule, the user explicitly picks the sort axis (mana value, name, color, or price) via the new global "Ordenar por" control, with name always the tiebreak.
- `deck-analytics`: the "Mana curve chart" requirement excludes land cards from every bucket. **This delta is drafted but not yet written** — `specs/deck-analytics/spec.md` doesn't exist yet in this change; create it via `/opsx:continue` using the content already reviewed for this update.
- `deck-analytics`: the "Color-distribution chart" requirement gains a "Terrenos" bucket counting all land cards, separate from the color-identity buckets (which now count only non-land cards). Same deferred-to-`/opsx:continue` delta file as the mana curve change above.

Every other existing spec requirement (drag-and-drop, illegal/over-budget distinguishability, budget and card-count computation and visual states, analytics chart scoping and live recomputation) continues to hold exactly as written; only the visual implementation of already-required behavior changes.

## Impact

- **Code**: `extension/src/ui/panel.css` (full rewrite of tokens and component rules, deletion of dead overlay rules, new `--c500-mana-land` token), `extension/src/tab/TabRoot.tsx` (layout restructure, three-column main content, no `onRemoveCard` for Comandante, new sort-axis state and select), `extension/src/ui/components/BudgetGauge.tsx` (used+remaining display), `CardCountGauge.tsx`, `LegalitySummary.tsx`, `ExportMenu.tsx` (consolidated into the ledger tape — component boundaries may be reshaped), `CardRow.tsx`, `CardVisualTile.tsx` (color-identity rail, conditional name caption, larger quantity input), `charts/BarChart.tsx` (per-bucket color support), `ZoneSection.tsx` (Commander hero treatment, multi-column list layout, Companheiro shrink-when-empty, zone label renames, group-count display), `extension/src/lib/organizer/group-sort.ts` (user-selectable sort axis, replacing the fixed multi-axis tiebreak), `extension/src/lib/analytics/bucket-counts.ts` (land exclusion in `manaCurveBuckets()`, new Terrenos bucket in `colorBuckets()`).
- **Tests**: existing component tests (`BudgetGauge.test.tsx`, `CardCountGauge.test.tsx`, `CardRow.test.tsx`, `CardVisualTile.test.tsx`, `ZoneSection.test.tsx`, `charts/BarChart.test.tsx`, `TabRoot`-adjacent tests) assert behavior, not class names/DOM shape where avoidable, but some will need updates to match consolidated/restructured components.
- **No dependency, API, storage, or manifest changes.**
